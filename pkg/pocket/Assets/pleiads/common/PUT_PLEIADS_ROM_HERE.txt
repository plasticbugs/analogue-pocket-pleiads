Put pleiads.rom and/or phoenix.rom in this directory.

One core plays both games. Choosing Run lists them by name and nothing loads
until you pick one. Those entries are the .json files one folder up, in

    Assets/pleiads/plasticbugs.pleiads/

so that folder and this one both have to be on the card. Each entry names the
image it needs -- which is also how an updater such as pupdate knows to fetch
both -- so the files must be called exactly pleiads.rom and phoenix.rom. A game
whose image is missing will not load; the other still works.

The core is FPGA gateware: it cannot unzip a romset or run a script, so the
image has to be assembled on a computer first. From a checkout of the core:

    python3 tools/mra_build.py pleiads.mra /path/to/pleiads.zip
    python3 tools/mra_build.py phoenix.mra /path/to/phoenix.zip

Each produces a 25,088-byte .rom file. Every part is CRC-checked on the way in
and the finished image is verified against a checksum recorded in the .mra, so
a wrong or damaged romset is reported rather than silently producing a core
that does not run.

No ROMs are distributed with this core.
